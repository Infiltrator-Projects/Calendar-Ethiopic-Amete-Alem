# Ethiopian Amete Alem Calendar

Amete Alem calendar semantics and display rules remain solely in this repository. Common 1.19.80 (dc4aac326964ca4400b6e21851d16eea674040c8) owns neutral arithmetic, coordinate conversion and public provider ABI. This provider builds the actual Common static library via its exact submodule, removing duplicate Common copies. Native releases embed the pinned source for offline builds, preserving regression tests.
